行事曆 App 隱私權政策

最後更新：2026 年 9 月 4 日

簡短版：這是一個個人自用的行事曆工具，只有開發者本人使用。它讀寫你自己的 Google 日曆與 Google Tasks，資料只留在你自己的裝置和你自己的 Google 帳戶裡，不會傳送到任何伺服器，也不會提供給任何第三方。

一、這個應用程式是什麼

「行事曆」（專案代號 2026-calendar）是一個個人使用的網頁應用程式（PWA），用來檢視與管理使用者自己的 Google 日曆行程與 Google Tasks 待辦事項。它由 Charlie Wang 開發，僅供開發者本人使用，不對外提供服務、不收費、沒有其他使用者。

二、我們存取哪些資料

在你透過 Google 授權之後，本應用程式會使用以下 Google API 權限範圍：

  • https://www.googleapis.com/auth/calendar：讀取與寫入你的 Google 日曆行程，用於在應用程式中顯示、新增、編輯、刪除行程。
  • https://www.googleapis.com/auth/tasks：讀取與寫入你的 Google Tasks，用於顯示與管理待辦事項。

本應用程式不會存取你的電子郵件、聯絡人、雲端硬碟檔案、相片或其他任何 Google 服務資料。

三、資料如何被使用與儲存

  • 行程與待辦資料只用於在你自己的畫面上顯示與編輯，不做任何分析、統計或側寫。
  • 為了支援離線瀏覽，資料會暫存在你自己瀏覽器的本機儲存空間（localStorage）。清除瀏覽器資料即可刪除。
  • 本應用程式沒有後端伺服器，不會把你的行事曆資料傳送到開發者或任何第三方的伺服器。所有 API 請求都由你的瀏覽器直接對 Google 發出。
  • 另有一支在使用者自己的個人電腦上執行的排程程式，每天早上讀取當日行程並整理成一則摘要，透過 LINE 傳送給使用者本人。該程式的授權憑證只存在使用者自己的電腦裡。

四、資料分享

本應用程式不會將你的資料出售、出租、交換或以任何形式提供給第三方，也不會用於廣告或行銷用途。除了與 Google API 通訊之外，沒有任何對外的資料傳輸。

五、資料保留與刪除

  • 瀏覽器端的快取：清除該網站的瀏覽器資料即可完全刪除。
  • 撤銷授權：前往 Google 帳戶的第三方應用程式存取權頁面，移除本應用程式即可立即終止所有存取權限。
  • 你的行程與待辦本身存在你自己的 Google 帳戶中，撤銷授權不會刪除它們。

六、安全性

本應用程式使用 Google 官方的 OAuth 2.0 授權流程，開發者不會取得也不會儲存你的 Google 密碼。存取權杖僅暫存於瀏覽器記憶體中，關閉分頁後即失效。

七、Google API 服務使用者資料政策

本應用程式對 Google API 所取得資訊的使用與轉移，均遵守 Google API 服務使用者資料政策，包括其中的「有限使用」（Limited Use）要求。

八、政策變更

本政策如有變更，將直接更新於本頁面，並更新頁首的最後更新日期。
